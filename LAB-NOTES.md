# Lab 04 — Review an Agent-Generated Pull Request (staged branch)

This branch carries one feature commit, made by an AI coding agent given this task:

> "Add a numeric severity score to the triage summary so ops can sort logs by risk."

## What to do

1. In **your copy** of this repo, open a pull request from `review-me` into `main`.
2. Paste the contents of `PULL-REQUEST.md` as the PR description — that's the description the
   agent wrote for its change.
3. Apply the course's review checklist to the PR, phase by phase, in order.
4. There are **at least four planted issues** in this PR. Find them, and leave the review comment
   you would actually leave on each — line-anchored, specific, actionable.
5. Do **not** merge. When you're done, your instructor walks the PR with the class.

A hint that is not a spoiler: the checklist's ordering exists because attention is scarce. Trust
the order — the cheapest checks catch more than you'd think.

*All planted "secrets" on this branch are synthetic — shape-correct, invalid, unusable — so
scanners have something real-shaped to catch. Do not replace them with real values.*
